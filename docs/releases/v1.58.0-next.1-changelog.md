## @backstage/plugin-scaffolder-react@3.1.0-next.1

### Minor Changes

- 4595cd3: The review step now masks a field whenever any parameter step marks it as a password or secret, or sets a review mask for it. This includes steps hidden by a `when` condition, and no longer depends on which step declares the field first.

  Custom review step components now also receive the complete form state as `schemaFormState` and all parameter steps, including hidden ones, as `allSteps`. Forward these to `ReviewState` as `schemaFormState` and `maskSchemas` to keep the same masking behavior as the built-in review step. The steps passed to custom review step components are now typed with their `title`, so they can be passed to `ReviewState` as `schemas` without a type error. Code that builds these props by hand, for example in tests, now needs to include a `title` for each step.

## @backstage/core-app-api@1.20.9-next.1

### Patch Changes

- c046db6: The legacy React Aria router bridge now leaves absolute and protocol-relative link URLs to the browser instead of passing them to React Router's `navigate`. React Aria client-navigates same-origin absolute URLs, and since React Router 6.30.5 those resolved to broken in-app paths such as `/https:/example.com/page`.
- Updated dependencies
  - @backstage/ui@0.20.1-next.0

## @backstage/core-components@0.18.17-next.1

### Patch Changes

- 113ef6e: Improved the rendering performance of sidebars with many items. Sidebar items now share their styles instead of each adding their own style sheets.
- 393107a: Deprecated `Lifecycle`, `TrendLine`, `GaugeCard`, `FeatureCalloutCircular`, `SimpleStepper`, `SimpleStepperStep`, and their associated types. Existing behavior is unchanged.

  Use `Text` or `Badge` from `@backstage/ui` for lifecycle labels, a suitable charting library for trend visualizations, and compose a gauge with a card. Compose application-specific onboarding and workflows in place of the callout and stepper components.

- Updated dependencies
  - @backstage/ui@0.20.1-next.0
